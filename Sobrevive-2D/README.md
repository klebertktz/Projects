# Sobrevive 2D

Meu primeiro jogo de sobrevivência 2D, desenvolvido com Unity e C# para praticar programação e desenvolvimento de jogos.

## Como jogar

Clique no botão de início e use **W, A, S e D** para se movimentar. Desvie dos inimigos e sobreviva pelo maior tempo possível. A pontuação aumenta com o tempo de sobrevivência. Ao perder todas as vidas, use o botão de reiniciar para tentar novamente.

## Recursos

- Movimento em oito direções.
- Inimigos que perseguem o jogador.
- Surgimento de inimigos e dificuldade progressiva.
- Sistema de vidas e invulnerabilidade temporária após sofrer dano.
- Indicadores de vidas, tempo e pontuação.
- Menu inicial, tela de fim de jogo e reinício.
- Efeitos sonoros e arquivo de música incluído.

## Abrir na Unity

1. Baixe ou clone este repositório.
2. No Unity Hub, adicione a pasta **Sobrevive-2D** como projeto.
3. Use a versão **6000.6.6f1**, registrada em `ProjectSettings/ProjectVersion.txt`.
4. Aguarde a importação dos arquivos e pacotes.
5. Abra `Assets/Scenes/Main.unity` e pressione **Play**.

Este diretório contém o projeto-fonte. Não inclui um executável pronto para jogar.

## Aprendizados

Prática de C#, componentes, prefabs, colisões 2D, corrotinas, interface e controle de cenas.
